# 🌤️ Weather App

A sleek, responsive web application that provides real-time weather information for any city in the world. This project demonstrates API integration, asynchronous JavaScript, and dynamic UI updates.

## ✨ Features
* **Real-time Weather:** Get current temperature, humidity, and wind speed.
* **City Search:** Search for weather data by city name.
* **Dynamic Icons:** Weather icons change based on current conditions (sunny, rainy, cloudy, etc.).
* **Responsive Design:** Fully functional on mobile, tablet, and desktop screens.

## 🚀 Tech Stack
* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **API:** [OpenWeatherMap API](https://openweathermap.org/api)
